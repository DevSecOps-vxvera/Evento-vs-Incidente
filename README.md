# ¿Evento o incidente? · Reto interactivo

Actividad web estática en español para practicar la clasificación de eventos e incidentes de ciberseguridad. Incluye 14 escenarios tradicionales y de IA/deepfake con explicación inmediata, puntuación y revisión de respuestas.

## Probar localmente

Abre `index.html` en un navegador. No requiere instalación, compilación, dependencias ni backend.

## Publicar con GitHub Pages

1. Copia los archivos de esta carpeta a la raíz de tu repositorio de GitHub (o publica esta carpeta desde una rama de tu repositorio).
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/ (root)`; guarda los cambios.
4. Espera a que GitHub complete la publicación y abre la URL indicada en la misma sección.

## Alcance

Los escenarios son ficticios. La actividad presenta un criterio didáctico general basado en NIST: un incidente es una ocurrencia que compromete o amenaza la confidencialidad, integridad o disponibilidad, o implica una violación de políticas. Cada organización debe aplicar sus definiciones y umbrales aprobados. No se almacenan ni transmiten las respuestas; el estado se conserva solo en la página abierta.
